# 🚀 LeetCode Journey: Cracking the DSA Basics

Welcome to my LeetCode Journey! This repository serves as a personal sandbox and tracker as I dive headfirst into the world of Data Structures and Algorithms (DSA). 

Instead of just collecting solved problems, this repo is a testament to the consistency, late-night debugging, and "aha!" moments that come with mastering foundational computer science concepts.

---

## 🎯 The Mission

The goal of this journey isn't to memorise solutions, but to reshape how I approach problem-solving. By solving problems primarily in **Python**, I am focusing on:
*   **Core Data Structures:** Understanding when and why to use Arrays, Hash Maps, Linked Lists, Trees, and Graphs.
*   **Algorithmic Thinking:** Transitioning from "how do I code this?" to "how do I optimize this?" (Time & Space Complexity).
*   **Consistency:** Showing up daily to tackle new challenges, embrace the grind, and build long-term coding stamina.

---

## 🛠️ Tech Stack & Tools

*   **Language:** Python 🐍 (Chosen for its clean syntax, allowing me to focus heavily on logic rather than boilerplate code).
*   **Automation:** [LeetHub](https://github.com/QasimWani/LeetHub) (Automatically syncing my successful LeetCode submissions straight to this repository).

---

## 🧠 Key Takeaways So Far

> "The only way to learn a new programming language or algorithmic concept is by writing programs in it."

Through this process, I've learned that getting a `Time Limit Exceeded (TLE)` or a `Wrong Answer` is just part of the process. Every failed submission is a step closer to a more optimal, elegant solution.
